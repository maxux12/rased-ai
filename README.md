# الراصد الذكي — PWA مجانية للآيفون

## التشغيل
ارفع محتويات مجلد `pwa` إلى مستودع GitHub عام مخصص للواجهة (لا ترفع أسراراً أو بيانات شخصية)، ثم فعّل Settings → Pages → Deploy from a branch → main / root. بعد ظهور عنوان HTTPS افتحه في Safari على الآيفون، ثم مشاركة → إضافة إلى الشاشة الرئيسية.

يمكن استخدام أي استضافة ملفات ثابتة مجانية تدعم HTTPS. عند عدم وجود خادم يعمل وضع الإرشاد المحلي ولا يتحقق من صحة الخبر. أرشيف التقارير محفوظ محلياً في المتصفح على الجهاز وقد يُمسح عند حذف بيانات الموقع.

## الخادم الاختياري
مجلد `backend` في جذر المشروع يحتوي FastAPI و`/check` و`/health`. يتطلب استضافة Python مستقلة وHTTPS وضبط CORS على نطاق الواجهة. لا تضع مفتاح OpenAI في الواجهة؛ تكامل OpenAI اختياري ومدفوع غالباً. البحث الحالي عبر Google News RSS يقدم روابط مرشحة فقط، ولا يتحقق من الادعاءات آلياً. الخادم الأصلي غير معد للنشر العام دون ضبط مصادقة ومحددات معدل الطلبات وCORS وحماية إساءة الاستخدام.

## القيود
مشاركة iOS المباشرة من تطبيقات أخرى إلى PWA ليست مضمونة؛ النسخ واللصق مدعومان. الوصول إلى منشورات Facebook الخاصة أو المقيدة غير مدعوم. لا يوجد تحليل صور أو كشف نسخ متقدم في هذا الإصدار. لا تستخدم النتائج كتصديق رسمي.
